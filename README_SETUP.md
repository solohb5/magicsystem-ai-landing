## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Open browser:**
   Navigate to `http://localhost:3000`

## 🛠️ Technology Stack

- **Framework:** Next.js 15 with TypeScript
- **Styling:** Tailwind CSS with custom design system
- **Animations:** Framer Motion + custom WebGL effects
- **Calendar:** React Calendly integration
- **Performance:** Optimized for <2s load times
- **Analytics:** Custom tracking with GA4/Facebook Pixel support

## 🔧 Customization

### Calendly Integration
Replace the placeholder in `CalendlySection.tsx`:
```javascript
// Replace with your actual Calendly URL
data-url="https://calendly.com/your-account/transformation-call"
```

### Analytics Setup
Add your tracking IDs to the analytics component:
- Google Analytics 4
- Facebook Pixel
- Custom event tracking

### Content Updates
All copy is contained in component files for easy editing:
- Hero headlines in `HeroSection.tsx`
- Case studies in `CaseStudiesSection.tsx`
- FAQ content in `FAQSection.tsx`
